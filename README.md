# 🧪 Lab_game

Сайт-каталог всех игр Яндекс Игр + возможность создавать и публиковать свои собственные игры.

## Возможности

- **Каталог игр** — подборка популярных игр в стиле Яндекс Игр
- **Регистрация и вход** — простой аккаунт (хранится локально в браузере)
- **Создание игр двумя способами:**
  1. **С помощью ИИ** — опиши идею, и игра сгенерируется автоматически
  2. **Сборка вручную** — собери игру из готовых блоков (Игрок, Враг, Платформа, Монета и т.д.)
- **Публикация** — созданные игры сразу появляются в общем каталоге
- **Смена темы** — светлая / тёмная (по умолчанию светлая)

## Как запустить

1. Открой репозиторий → **Settings → Pages**
2. Source: **GitHub Actions**
3. Сайт будет доступен по адресу:  
   `https://superyaroslav8-arch.github.io/Lab_game/`

Или просто открой `index.html` локально в браузере.

## Технологии

- Чистый HTML + CSS + JavaScript
- Данные хранятся в `localStorage` браузера
- Адаптивный дизайн
- Поддержка светлой и тёмной темы
